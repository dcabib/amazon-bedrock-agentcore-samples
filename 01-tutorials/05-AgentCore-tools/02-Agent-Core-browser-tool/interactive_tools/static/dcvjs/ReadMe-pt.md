# Amazon DCV Web Client SDK

O Amazon DCV Web Client SDK é uma biblioteca JavaScript que permite
desenvolver sua própria aplicação cliente web do Amazon DCV.
Os usuários de sua aplicação poderão se conectar e interagir com
uma sessão nativa do Amazon DCV.

## Pré-requisitos

Antes de começar a trabalhar com o Amazon DCV Web Client SDK, certifique-se
de que você está familiarizado com o Amazon DCV e sessões do Amazon DCV. Para mais
informações, consulte o [Amazon DCV Administrator Guide](https://docs.aws.amazon.com/dcv/latest/adminguide).

O Amazon DCV Web Client SDK suporta o servidor Amazon DCV versão 2020
e posteriores.

## Suporte a Navegadores

O Amazon DCV Web Client SDK suporta JavaScript (ES6) e pode
ser usado de aplicações JavaScript ou TypeScript.

O Amazon DCV Web Client SDK suporta os seguintes navegadores web:
 * Google Chrome - Últimas três versões principais
 * Mozilla Firefox - Últimas três versões principais
 * Microsoft Edge - Últimas três versões principais
 * Apple Safari para macOS - Últimas três versões principais

Embora o SDK seja projetado para funcionar com versões mais recentes de navegadores,
ele pode ser transpilado para código ES5 e usado com navegadores mais antigos. Neste
caso, alguns recursos ou funcionalidades podem não estar disponíveis.

## Versionamento

O Amazon DCV Web Client SDK segue o modelo de versionamento semântico.
A versão tem o seguinte formato: major.minor.patch. Uma mudança na
versão principal, como de 1.x.x para 2.x.x, indica que mudanças
incompatíveis que podem exigir alterações de código e uma implantação
planejada foram introduzidas. Uma mudança na versão menor, como de
1.1.x para 1.2.x, é compatível com versões anteriores, mas pode incluir
elementos descontinuados.
